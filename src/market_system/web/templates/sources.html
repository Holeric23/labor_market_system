Источники и сбор

Сбор выполняет отдельный исполнитель. Расписание выключено по умолчанию. Настройка Telegram-сессии выполняется отдельно через CLI в новом проекте.

Telegram: сначала запустите историю; повтор истории продолжит её загрузку. Регулярный сбор проверяет новые сообщения и ограниченный недавний период. Все старые правки и удаления не обнаруживаются.

DesignHunters: собираются только URL из локального CSV (первый столбец, без заголовка). Автоматическое обнаружение новых URL не поддерживается. Регулярный сбор повторно проходит этот список.
